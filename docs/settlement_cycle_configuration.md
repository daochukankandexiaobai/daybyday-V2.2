# 结算周期配置说明

## 默认规则

新建数据库默认使用自然月结算：每月 1 日至当月最后一天。

例如，2026 年 7 月的结算周期为 `2026-07期`，范围为
`2026-07-01 ~ 2026-07-31`。

## 管理员配置

管理员登录后，在“系统设置”的“结算周期规则”区域可以：

1. 保持自然月结算；或
2. 在尚未录入日报、周目标、周期目标时，设置每月 1 至 28 日中的任意一天为周期起始日。

自定义周期仍按结束月命名。例如起始日设为 5 日时：

- `2026-07-05 ~ 2026-08-04` 显示为 `2026-08期`。

设置完成后应使用“确认并锁定”。锁定后，应用内不允许直接改动结算规则。

## 历史数据保护

已有日报、周目标或周期目标的数据库会自动保留历史兼容规则并锁定。迁移不会重写已有
`daily_records.settlement_cycle_code`，也不会删除或调整历史日报、周目标、导入日志或导出记录。

如确有需要在已有业务数据后更改规则，应采用后续版本的“新规则生效日 + 历史规则版本”方案，
而不是直接修改当前规则。
